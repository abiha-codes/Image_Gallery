
# 🖼️ Image Gallery

A modern and interactive Image Gallery built using **HTML, CSS, and JavaScript**. This project features a beautiful dark-themed design, smooth hover effects, category filters, and an interactive lightbox for viewing images.

## 🌐 Live Demo

[Click here to view the live website](https://image-gallery-azure-eta.vercel.app/)

## ✨ Features

- 🎨 Modern dark-themed UI
- 🖼️ Beautiful image gallery layout
- 🔍 Filter images by All, Nature, City, and Animals
- 💡 Interactive lightbox to view images
- ⏭️ Next and previous image navigation
- 🖱️ Smooth hover and transition effects
- 📱 Responsive layout for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
